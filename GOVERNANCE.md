# Governance boundary

ITERANT is the execution repository for iterative-computation research. It may generate models, experiments, diagnostics, and candidate submissions, but it does not authorize its own externally consequential actions.

For the One Layer Deeper campaign:

- the campaign code, run matrix, generated submissions, profiling, and immutable evidence live here;
- the work-package charter, Council reviews, decision lineage, and Human Steward authorization are referenced by INTELLECT;
- the machine Hard gate establishes eligibility only;
- each hosted Hard attempt requires explicit Human Steward approval;
- thresholds may not be relaxed after observing a candidate merely to admit it.

The original unmerged implementation in `grandchallenge/INTELLECT` is migration provenance, not the canonical code location.
